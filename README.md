# 🤖 Clawbot Agent - 微信智能时间规划助手

专为微信 Clawbot 打造的智能日程规划与时间管理系统。

---

## 🌟 核心特性

1. **统一管理控制台（默认运行在 5178 端口）**：
   - **用户注册与审核流**：用户直接输入账号密码注册，状态默认进入待审核池；系统管理员可在后台一键审核放行或拒绝。
   - **微信 Clawbot 对接**：专属 Webhook 回调地址、Token 自动生成与重置、Outbound 发送端点配置。
   - **LLM 大模型集成**：支持自定义 API 端点与 Key（默认预设 **DeepSeek**：`https://api.deepseek.com/v1`，模型 `deepseek-chat`）。
   - **日历双向同步**：
     - **导入外部日历**：支持导入 Apple 日历、Google 日历、Outlook 的 `webcal://` 或 `https://` ics 订阅链接，自动规避忙碌时间段。
     - **专用 TODO 日历导出**：提供 `webcal://` 专属订阅链接，由 Clawbot 智能规划的日程实时同步至系统日历。
   - **日历日程全景视图与 TODO 看板**：周视图/日视图展示外部日程与规划待办，支持一键完成、延时、重新计算排程。

2. **自然语言处理与排程闭环**：
   - **轻量且低成本**：所有 LLM 调用仅发生在用户发送微信消息时进行结构化抽取；所有的回复消息均通过**高确定性模版 + 内容拼接**完成，杜绝大模型幻觉与高额成本。
   - **多轮槽位补齐**：若用户未一次性提供关键字段（耗时、截止时间 DDL、紧急程度、重要度），助手自动使用规范模板反问补齐。
   - **智能排程算法**：多段工作时间段计算（如 `09:00-12:00`、`13:00-18:00`、`19:00-24:00`、`00:00-02:00`）扣除外部日历事件与已有待办，利用动态评分在空闲槽位中智能放入任务。

3. **主动提醒与用户状态汇报闭环**：
   - **开始前提醒**：事件开始前 X 分钟自动推送微信提醒。
   - **结束前核对**：事件快结束时推送微信提醒询问是否已完成。
   - **交互反馈**：支持直接回复“已完成”（释放剩余空闲）、“延长30分钟”（动态延长并校验冲突）、“重新安排”。

## 🚀 快速启动

### 1. 安装依赖
本项目已配置好 Node.js + TypeScript 全栈环境：
```bash
pnpm install
```

### 2. 启动服务

您可以通过以下命令同时启动后端服务（端口 3001）与管理后台（端口 5178）：
```bash
pnpm dev
```
或分别启动：
```bash
# 启动后端 API 服务
pnpm dev:server

# 启动前端控制台 (端口 5178)
pnpm dev:client
```

打开浏览器访问：**`http://localhost:5178`**

---

## 🔑 初始管理员账号

系统在初次启动时已自动初始化超级管理员账号：
* **账号**：`admin`
* **默认密码**：系统配置中预设的管理员密码（初次登录后请及时在后台修改）

登录后即可进入管理控制台，可在右上角「用户审核」面板中对新注册的用户进行审核放行。

---

## 📱 微信 Clawbot 对接指南

1. 登录管理后台（`http://localhost:5178`）进入「**设置 & 对接**」页面；
2. 填入您的 **DeepSeek API Key**（若已有系统环境变量 `DEEPSEEK_API_KEY` 也会自动读取）；
3. 复制页面中的 **Clawbot Webhook 地址**：
   ```text
   http://<您的服务器IP或域名>:5178/api/webhook/clawbot/<您的Token>
   ```
4. 将该链接配置给您的微信 Clawbot 机器人的消息回调地址；
5. 若需要机器人主动发送开始/结束提醒，请填写「Clawbot 发送消息 API 端点」与您的微信 wxid；
6. 可以在后台顶部的「**对话模拟**」标签页中，直接在网页内模拟发送微信消息进行实时联调与体验！
